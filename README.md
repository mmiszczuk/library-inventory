# library-inventory
A simple Java console application for managing library inventory.

# Current Status
Currently this project consists of the initial file setup and a simple CLI menu system.

This is my first java project and I'm slowly learning through this project.

## Project Structure

```text
Library-inventory/
├── .gitignore
├── README.md
└── src/
    ├── Book.java       # Represents a book item in the library (extends Item)
    ├── Input.java      # Handles user input and CLI menu prompts
    ├── Item.java       # Base class for library items
    ├── Main.java       # Application entry point and menu loop
    └── Member.java     # Represents library members
```
